# 100K Views Script Generator

A script generator tool built on the **Chris Chung "100K Views in 11 Seconds"** framework.

🔗 **Live App:** https://GITHUB_USERNAME.github.io/100k-script-generator

## Channels Supported
- ⚔️ War Cipher — Military History (English)
- 🔬 Body Horror — Science Facts (Telugu/English)
- 🧠 Dopamend — Science Curiosity (Telugu)
- 🤖 Polemod — AI Debate (English)
- 💻 DevOps/Tech — Career Content (English)

## Framework
1. **High TAM Idea** — Topic interesting to many
2. **Curiosity in 3s** — "Most think X BUT actually Y"
3. **Super Hook** — Why should I listen to you?
4. **Speed 2 Value** — Dive into value immediately
5. **Create Tension** — BUT and SO, not "and then"
